# Chapter 3 Single Table Queries

## Overview
___
This chapter focuses on writing SQL queries using a single table from the Sakila database. 
The 10 queries demonstrate the use of SELECT, functions, WHERE, ORDER BY, aliases, filtering operators, and LIMIT.

### New Concepts
___
- **SELECT clause**
  - Arithmetic expressions
  - Column aliases
  - `DISTINCT`
  - `LIMIT`

- **Functions**
  - `CONCAT()`
  - `LEFT()` / `RIGHT()`
  - `ROUND()`
  - `CURRENT_DATE()`
  - `DATE_FORMAT()`

- **WHERE clause**
  - Comparison (relational) operators
  - Logical operators
  - `IN` and `BETWEEN`
  - `LIKE` and `REGEXP`
  - `IS NULL` / `IS NOT NULL`
  - Filter by a calculation

- **ORDER BY clause**
  - `ASC` and `DESC`
  - Sort by more than one column
  - Sort by an alias

## Installation
___
1. Clone the repository to your local machine. (Or just steal my code.)
2. Install MySQL if it is not already installed.
3. Download and install the Sakila sample database.
4. Open the project in VS Code or your preferred SQL editor.
5. Select the Sakila database before running the queries.
6. Run each query individually to verify the results.

## Learning Outcomes
___
- Write properly formatted SQL SELECT statements.
- Use arithmetic expressions within a query.
- Create readable column aliases.
- Remove duplicate results using DISTINCT.
- Limit the number of rows returned with LIMIT.
- Use common MySQL functions to manipulate and format data.
- Combine conditions using logical operators.
- Filter data using IN and BETWEEN.
- Search text using LIKE.
- Identify NULL values using IS NULL and IS NOT NULL.
- Filter results using calculated values.
- Sort results using one or multiple columns.
- Sort query results using column aliases.
- Format dates and numerical values for easier readability.
- Write readable and properly documented SQL queries.
